Не является мультимодульным проектом. Producer и Consumer для удобства собраны в одном месте.
Product service - Produser системы производит и отправляет сообщения в Kafka-broker
Email-notification service - Consumer системы, который считывает сообщения из Kafka-брокера

Кластер кафки разворачивается на стороне продюсера через Docker-compose 
(Потом можно вынести в отдельный сервис)
