Проект стал мультимодульным, для удобства. Producer и Consumer для удобства собраны в одном месте.
docker-compose с развертыванием кластера Kafka вынесен в корень проекта 

 - **product-service** - Produser системы производит и отправляет сообщения в Kafka-broker
 - **email-notification-service** - Consumer системы, который считывает сообщения из Kafka-брокера
 - **mock-service** - сервис-заглушка, для проверки логики работы NotRetryableException и RetryableException
 - **core** - модуль-библиотека, куда вынесены эвенты, чтобы не дублировать их по сервисам Producer и Consumer

1) Для сборки и запуска проекта необходимо поднять кластер Кафки в Docker
2) Собрать проект с помощью Maven
3) Запустить сервис-заглушку
4) Поднять сервис Producer
5) Поднять сервис Consumer
6) Для Удобства взаимодействия с кластером, можно пользоваться или UI, который открывается 
в Swagger или пользоваться исполняемыми скриптами
